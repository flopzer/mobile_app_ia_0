# Configuration Gmail pour l'Email Agent

Pour utiliser l'Email Agent, vous devez créer un mot de passe d'application Gmail.

## Étapes de configuration

### 1. Activer la validation en deux étapes

1. Allez sur https://myaccount.google.com/security
2. Trouvez "Validation en deux étapes"
3. Activez-la si ce n'est pas déjà fait

### 2. Créer un mot de passe d'application

1. Allez sur https://myaccount.google.com/apppasswords
2. Sélectionnez "Mail" comme application
3. Sélectionnez "Autre" comme appareil
4. Entrez un nom (ex: "Chatbot IA")
5. Cliquez sur "Générer"
6. Copiez le mot de passe généré (16 caractères sans espaces)

### 3. Utiliser le mot de passe

- **Email** : Votre adresse Gmail complète (exemple@gmail.com)
- **Mot de passe** : Le mot de passe d'application généré (pas votre mot de passe Gmail normal)

## Sécurité

- Ne partagez jamais votre mot de passe d'application
- Vous pouvez le révoquer à tout moment depuis votre compte Google
- Le mot de passe est stocké temporairement en mémoire uniquement
